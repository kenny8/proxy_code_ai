# Claude Desktop

GUI приложение для запуска локального прокси-сервера и Claude Code через удобный графический интерфейс.

## Описание

Приложение предоставляет интерфейс для управления UVicorn сервером (прокси) и запуска Claude Code с подключением к локальному серверу. Разработано для упрощения рабочего процесса с Claude Code при использовании кастомного API-прокси.

## Особенности

- **Тёмная премиальная тема** — кастомный дизайн на customtkinter с карточками, иконками и цветовой индикацией
- **Запуск/остановка сервера** — управление UVicorn сервером на `localhost:8082` одной кнопкой
- **Выбор папки прокси** — возможность указать директорию с сервером
- **Выбор рабочей папки** — выбор директории для запуска Claude Code
- **Debu** — переключатель уровня логирования (debug/info)
- **Просмотр логов** — встроенная панель логов сервера (открывается справа, окно адаптируется)
- **Админ-панель** — быстрый переход в веб-интерфейс администрирования
- **Копируемая справка** — все команды в одном окне с поддержкой Ctrl+C
- **Авто-иконка** — иконка приложения в заголовке и панели задач

## Использование

1. **Запуск сервера**
   - Нажмите "Запуск сервера"
   - Сервер запускается без видимого окна консоли, логи пишутся во встроенную панель
   - Сервер работает на `http://localhost:8082`

2. **Выбор папок (опционально)**
   - **Папка прокси** — директория с UVicorn сервером (по умолчанию `D:/free-claude-code`)
   - **Рабочая папка** — директория для запуска Claude Code (по умолчанию `D:/agent_work_claud/agent_workspace`)

3. **Просмотр логов**
   - Нажмите "Логи" — панель откроется справа, окно расширится
   - Повторное нажатие скрывает панель и сужает окно

4. **Debug-режим**
   - Переключатель справа от кнопки запуска сервера
   - ON — `--log-level debug` (подробные логи)
   - OFF — `--log-level info` (только основные события)

5. **Запуск Claude Code**
   - Убедитесь что сервер запущен (зелёный индикатор)
   - Нажмите "Claude Code"
   - Откроется окно PowerShell с запущенным Claude Code

6. **Остановка сервера**
   - Нажмите "Остановить сервер" для корректного завершения

## Команды которые использует приложение

### Запуск сервера
```bash
cd D:/free-claude-code && uv run uvicorn server:app --host 0.0.0.0 --port 8082
```

### Запуск Claude
```powershell
$env:CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY="true"; $env:ANTHROPIC_AUTH_TOKEN="freecc"; $env:ANTHROPIC_BASE_URL="http://localhost:8082"; cd "ПАПКА"; claude
```

## Переменные окружения

| Переменная | Значение | Описание |
|------------|----------|----------|
| `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY` | `true` | Обнаружение моделей шлюза |
| `ANTHROPIC_AUTH_TOKEN` | `freecc` | Токен аутентификации |
| `ANTHROPIC_BASE_URL` | `http://localhost:8082` | Адрес локального прокси-сервера |
